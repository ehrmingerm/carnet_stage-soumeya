# Espace du stage de Souméya

Pages du stage : espace du stage, guide d'accueil, fiche de mission, document de départ, carnet de suivi et son guide.

Le carnet ne contient aucune donnée. Les saisies sont enregistrées dans un dépôt privé, accessible uniquement au tuteur et à la stagiaire. Pour les afficher, il faut se connecter avec un jeton GitHub qui donne accès à ce dépôt.

Adresse de l'espace : https://ehrmingerm.github.io/carnet_stage-soumeya/espace.html
Adresse du carnet : https://ehrmingerm.github.io/carnet_stage-soumeya/
